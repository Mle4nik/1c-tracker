# 1С Developer Quest

Игровая карта прохождения курсов Stepik. Прогресс подтягивается автоматически, отмечать ничего не нужно.

## Запуск

1. Создай файл `.env` в корне проекта:
   ```
   STEPIK_CLIENT_ID=...
   STEPIK_CLIENT_SECRET=...
   ```
2. Команды:
   ```bash
   npm install
   npm run dev
   ```
3. Открой адрес Vite (обычно http://localhost:5173).

Данные обновляются при открытии сайта (если прошло больше 15 минут) и по кнопке с временем синхронизации.
Секрет Stepik хранится только на сервере и в браузер не попадает.

## Как это работает

- **XP** = пройденные шаги Stepik (+30 XP за мини-проект). **Уровень** растёт всё медленнее: следующий уровень L требует 10·L² XP.
- **Этапы** собираются из разделов курсов. Открываются по мере прохождения: пройденный, текущий и следующий видны, дальше замок. Начатый этап открывается сразу.
- **Мини-проект** для портфолио в этапе 8 — единственная ручная отметка.
- **Бонус** (бухучёт) даёт XP, но не нужен для прохождения этапов.

## Что править

`quest.config.json` — какие разделы входят в какой этап. Раздел указывается по `id`, поле `note` — просто подпись.
`data/snapshot.json` — последний снимок Stepik (обновляется синхронизацией).
